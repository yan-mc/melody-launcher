================================================================
 MCLauncher 5.31  ·  使用说明
================================================================

【这是什么】
Minecraft 启动器，作者：忘却的旋律。
全新独立前端 + 内置无头内核引擎，单文件绿色版：
整个程序只有一个 MCLauncher.exe，双击即用，无需安装、无需 .NET 运行时。

【第一次使用】
1. 把 MCLauncher.exe 放到任意文件夹（不要放 C:\Program Files）
2. 双击运行 → 「第一次进入游戏」设置窗：游戏名字 / 最大内存 / java 路径
3. 点「完成设置」→ 主界面
4. 点「更新游戏」→ 下载中心 → 选分类和版本 → 点「下载」→ 选择安装类型（原版/Forge/
   Fabric/NeoForge/OptiFine/LiteLoader）→「开始下载」
5. 装完回主界面 → 点「启动游戏」

【主界面】
· 启动游戏 / 更新游戏 / 设置 / 版本设置
· 版本名显示框（只读，显示当前选中的已安装版本）
· 空白处右键 → 下载中心 / 版本设置 / 下载源 API / Mod 管理 / 社区资源 / 运行日志 / 关于 / 打开游戏目录

【下载中心】
· 顶部标题栏右侧 ✕ 或按 Esc 返回主界面
· 四个分类（与 内核引擎 一致）：正式版 / 预览版 / 远古版 / 愚人节版
· 点一行选中版本 → 点「下载」→ 安装类型子页：
    - 原版：只安装游戏本体
    - Forge / Fabric / NeoForge / OptiFine / LiteLoader：装到独立实例，不影响其它版本
    - 实例名留空自动命名（如 1.20.1-Fabric_0.19.5）
· 「社区资源」→ 打开社区资源子页

【版本设置】
· 左侧已安装版本列表；右侧 8 个标签页：
  概览（路径/占用/打开目录/重命名/删除）
  Mod（扫描/启用/禁用/打开 mods 目录）
  资源包 / 光影 / 存档 / 截图（列表 + 打开目录）
  日志（latest.log 末尾 + 崩溃分析）
  设置（内存 / Java / 窗口大小）

【社区资源】
· 5 类：Mod / 整合包 / 资源包 / 光影 / 数据包
· 关键词 + 版本 + 加载器 → 搜索（Modrinth；CurseForge 需 API Key）
· 选中结果后「下载到本地」（双击也行）：自动放进当前版本的隔离目录
  （版本隔离开启时是 versions/<版本>/mods 等，与 内核引擎 一致）
· 整合包会下载 .mrpack 并尝试调用内核安装

【微软登录（正版）】
· 右键菜单「账户（正版登录）…」或设置里「正版登录测试」
· 点「微软登录」→ 自动打开微软网页并复制设备代码 → 网页输入代码 → 回到启动器等待
· 默认使用 内置应用 ID；如失效可在账户页填入自己在 Azure 注册的应用 ID
· 登录成功后，启动游戏自动使用微软账户；离线登录仍可在设置里改游戏名

【设置】
· 游戏名字、密码、正版登录、最大内存、启动器皮肤、java 路径、调试模式、游戏目录等
· 版本显示为只读；切换版本请用「版本设置」

【数据位置】
· 启动器设置：%AppData%\MelodyLauncher\settings.json
· 下载源配置：%AppData%\MelodyLauncher\Api.json
· 引擎工作目录：%LocalAppData%\MelodyLauncher\jobs\
· 引擎副本：%LocalAppData%\MelodyLauncher\engine\内核引擎.exe（首次运行自动释放）
· Minecraft：默认 %AppData%\.minecraft（可在设置/首次设置中改）
· 版本隔离开启时，Mod/存档/资源包在 .minecraft\versions\<版本>\ 下
删除方式：删掉 MCLauncher.exe 与上述目录即可，不写系统服务/不装驱动。

【已知情况】
· CurseForge 下载需要 API Key（当前未内置，搜索只返回 Modrinth 结果）
· 微软登录走设备代码流程，需要网络能访问 login.microsoftonline.com
· 主题切换、赞助相关功能不包含
· 无自动更新、无数字签名；部分杀软可能误报「释放引擎再执行」
· 首次运行会释放引擎到本地目录（约 5.5MB），属正常行为
· 若指定 Java 无法使用，启动器会自动回退为自动选择 Java 并提示
